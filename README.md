# Login-Register-Edit

Projeto Node para registro e login de usuários usando localhost.

## Uso

1. Instale dependências:
   ```bash
   npm install
   ```
2. Configure variáveis de ambiente em `.env` se desejar:
   ```bash
   HOST=localhost
   PORT=3000
   MONGODB_URI=mongodb://localhost:27017/login-register-edit
   ```
3. Inicie o servidor local:
   ```bash
   npm start
   ```
4. Abra em `http://localhost:3000`
